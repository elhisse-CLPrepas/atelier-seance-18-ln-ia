# Prompt maître du Module 05 — adaptation S18 édition 2

Cette édition suit S17 version 3 : comprendre HTML, CSS, JavaScript et le navigateur à partir du mini-site fourni. Les anciennes sources conservées dans docs/sources sont historiques.

S18 : choisir un mini-site, renseigner ou préremplir les champs depuis quatre démonstrations, reformuler le contenu et exporter un prompt maître pour produire les fichiers et un pack ZIP avec Codex, GPT ou Claude Code dans VS Code.

Démonstrations : Déclic Web (formation), Jardin partagé (association), Atelier Terre Claire (artisanat), Portfolio Nadia (travaux graphiques). Chaque exemple est fictif et reste modifiable.

Le prompt reprend projet, public, besoin, source et limites, six sections, action et destination, pages, style, interactions, ressources et contraintes techniques. Il demande des fichiers HTML/CSS/JS séparés, des ressources locales, un README, un compte rendu de contrôle et une archive ZIP.

S19 : reprendre les sources, assembler la V1 et tester la destination après extraction et déplacement. S20 : améliorer selon un essai lecteur et conserver la V2 et sa preuve.

Fichiers S18 : 04-WEB/contenu-page-projet.md ; 02-PROMPTS/prompt-maitre-mini-site-S18.md ; 06-PORTFOLIO/preuve-S18.md ; entrée d’index ; relais-S19.md. Les carnets, preuves et décisions restent personnels. Aucun résultat ni aucune validation ne doit être inventé.

Calendrier d’automne : S17 le 20 novembre 2026 ; S18 le 23 ; S19 le 27 ; S20 le 30. Les dates d’été des affiches originales restent celles des supports historiques. Durée S18 proposée : 90 minutes ; la production peut se poursuivre après la séance.

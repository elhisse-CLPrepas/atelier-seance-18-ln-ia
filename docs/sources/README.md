# PACK DOCUMENTAIRE — SÉANCE 18

## Produire un mini-site V1

**Module :** 05 — De la page web simple à la mini-application statique déployable  
**Séance :** 18 — MANIPULER  
**Version :** V1  
**Statut :** À VALIDER  
**Durée proposée :** 90 à 120 minutes  
**Pilotage humain :** Prof. Abderrahman El Hisse

## Fonction du pack

Ce dossier rassemble les supports nécessaires pour préparer, animer, exécuter et contrôler la séance 18. Le candidat doit produire une première version locale de son mini-site comprenant HTML, CSS, JavaScript, README et preuve.

## Ordre recommandé

```text
1. Le formateur lit le support.
2. Le candidat complète sa fiche.
3. Le formateur confirme le cadrage.
4. Le candidat exécute les prompts 18-A à 18-F.
5. Le candidat contrôle le projet après chaque étape.
6. Le candidat complète la preuve 18.
7. Le formateur applique la checklist de réception.
```

## Limites

Le pack n’autorise ni JSON, ni API, ni PHP, ni PWA, ni ZIP de déploiement, ni publication. Ces éléments appartiennent aux séances suivantes.

**Statut maximal produit par l’IA :** `PRÊT POUR VALIDATION HUMAINE`.

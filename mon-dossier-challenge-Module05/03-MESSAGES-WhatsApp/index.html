Messages WhatsApp

Rédiger, relire, copier puis envoyer dans le groupe depuis WhatsApp.

1. Accès au groupe

Le fichier .env.whatsapp fourni reste local. Le lien mémorisé appartient à ce navigateur.

2. Préparer le message

Remplacez les champs [ENTRE CROCHETS]. Utilisez des URL directes et *du gras* au format WhatsApp.

3. Envoyer dans WhatsApp

Copiez le texte, ouvrez le groupe, vérifiez son nom, collez le message et appuyez sur Envoyer dans WhatsApp.

Consignez ensuite l’envoi réel dans le journal CSV. Cette page ne déclare aucun envoi automatique.
